Architecture

Four decoupled layers isolate terminal control from reasoning

The architecture separates the Textual Host from the Two-Tier Intelligence and the underlying Antigravity CLI runtime. A persistent Workspace Ledger guarantees crash recovery and state synchronization across both PTY sessions.

Workflow Lifecycle

Two hard checkpoints halt agent drift before code execution

The supervisor enforces two hard checkpoints. Checkpoint 1 locks the specification before task breakdown. Checkpoint 2 audits the implementation plan and terminates PTY 1 to free memory and token context.

Interface Anatomy

Four panes isolate automated logs from human escalation

The Textual TUI runs as a long-lived terminal dashboard. The developer watches autonomous progress, inspects raw agent output, and intervenes only when an escalation requires human judgment.

Intelligence Distribution

Fast reflex filters 90% of events before deep reasoning wakes

The supervisor uses a two-tier model hierarchy. The sub-200ms jev classifier handles high-frequency terminal monitoring and permission brokering. The heavy supervisor agent executes only on decision boundaries.

Five architectural decisions establish supervisor autonomy

The architecture document highlights five open design decisions. Each balances deterministic execution, human oversight, and cross-platform reliability.
